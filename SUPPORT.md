# Support

**Arazzo for VS Code — by ConnEthics** (`connethics.arazzo-vscode`) is free and open source under the MIT License.

## Community support

To ask a question, report a bug or request a feature, open an issue on [GitHub Issues](https://github.com/connEthics/arazzo-vscode/issues). Please search the existing issues first.

A useful bug report includes:

- the versions of the extension and of VS Code;
- the smallest Arazzo document that reproduces the problem, with its `arazzo:` version;
- the expected and actual behavior. For a validation issue, include the diagnostic code (for example `arazzo-step-target-exclusive`).
